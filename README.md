# shiqunix

在浏览器中配置 IQUNIX A80 键盘，无需安装驱动软件。

支持修改键位、调整背光、导入导出配置，以及测试按键输入。通过 WebHID 与键盘通信，配置操作在本机完成。

[打开网页](https://vacivor.github.io/shiqunix/)

## 使用

1. 使用桌面版 Chrome 或 Edge 打开网页。
2. 将键盘切换为有线模式，通过 USB 连接电脑，并关闭官方驱动。
3. 点击左侧键盘卡片，在弹出的窗口中选择设备。
4. 选择要修改的按键或灯效，调整后点击「应用修改」或「应用灯效」。

修改键位前可以导出配置备份。刷新网页后需要重新连接键盘。

## 功能

- **键位映射**：字母、数字、符号、修饰键、媒体控制、系统快捷键和灯光控制。
- **背光设置**：八种灯效，以及各模式支持的亮度、速度、全彩和单色设置；自定义模式支持指定颜色全亮或全灭。
- **配置管理**：导入、导出和重置键位。
- **键盘测试**：显示正在按下和已经测试过的按键。
- **Fn 组合键**：查看固定组合键的功能。
- **通信记录**：导出日志，便于反馈问题。

## 设备支持

当前适配 **IQUNIX A80**。界面中的 L80 选项仅用于切换键盘外观，尚不代表支持 L80 设备配置。

- Fn 组合键由键盘固件处理，暂不支持修改。
- Mac 模式下，四个特殊修饰键位置使用兼容映射；已通过的组合和适用范围见 [Mac 模式协议](docs/protocol/mac-mode.md)。键名可独立选择 Windows 或 macOS 显示。
- 键盘测试读取浏览器收到的输入，无法区分输入设备，也无法捕获所有系统快捷键。
- 自定义背光在断电后是否保留，尚未确认。

## 本地开发

使用 Node.js 24：

```sh
npm ci
npm run dev
```

访问 <http://127.0.0.1:5174/>。

```sh
npm run build          # 构建
npm run lint           # 代码检查
npm test               # 显示与映射测试
npm run test:research  # 包含抓包样本的完整协议回归
```

技术栈：Vite、React、TypeScript、Tailwind CSS 和 shadcn/ui。

## 协议文档

[A80 协议说明](docs/protocol/README.md)整理了 HID 报文、键位读写、动作编码、灯光参数、Mac 模式和固定 Fn 功能，并区分实机确认与静态推论。回归所需的精简报文样本也已收录，测试无需连接键盘。

## 发布

推送到 `main` 后，通过 GitHub Actions 发布到 GitHub Pages。首次部署时，将仓库 **Settings → Pages → Source** 设置为 **GitHub Actions**。
